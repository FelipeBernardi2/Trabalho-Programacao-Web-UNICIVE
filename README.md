# Trabalho-Programacao-Web-UNICIVE
Códigos feitos para o trabalho de programação web, passados pelo professor Gustavo Meneghetti Arcolezi

## Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/FelipeBernardi2/Trabalho-Programacao-Web-UNICIVE.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Trabalho-Programacao-Web-UNICIVE
   ```

3. Abra a pasta no Visual Studio Code.

4. Para executar as páginas, abra os arquivos `index.html` de cada exercício em um navegador.

> O projeto foi desenvolvido utilizando HTML e CSS, portanto não é necessário instalar dependências ou configurar um servidor para executar as páginas.
